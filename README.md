# Утилита просмотра VRM в браузере
Утилита позволяет открывать VRM-файлы и просматривать их в окне браузера. Просмотр реализован на основе библиотек @mrdoob/three.js и @pixiv/three-vrm

Управление окном просмотра целиком реализовано в `three.js` и осуществляется с помощью кнопок и колеса мыши.

Текущая версия **полностью** навайбкожена за 3 часа, поэтому обычные и антиблагодарности можете направить [alice.yandex.ru](https://alice.yandex.ru).

## Что реализовано
* Открывается файл VRM
* Отрисовывается модель в окне просмотра
* Модель приветствует вас!
